# 🛡️🗂️ PersonalOS — Archivio Personale & SecureVault (PWA 100% Offline)

Applicazione **Progressive Web App (PWA)** unificata e **100% Offline**, che integra **Archivio Personale** (Dashboard, Faldoni & Unità, Inventario Oggetti, Registro Prestiti) e **SecureVault Password Manager** (Crittografia locale AES-256-GCM + PBKDF2).

## 📦 Sezioni Incluse
1. **📊 Dashboard**: statistiche su Faldoni, Oggetti in Inventario, Valore Inventario (€), Prestiti Attivi e stato di SecureVault.
2. **📦 Faldoni & Unità**: creazione, modifica, filtro e stampa etichetta fisica con elenco degli articoli collegati.
3. **📋 Inventario Oggetti**: catalogo articoli collegato ai faldoni con quantità, stato, valore stimato e foto compressa in locale.
4. **🤝 Registro Prestiti**: gestione uscite/restituzioni con segnalazione automatica dei prestiti in ritardo.
5. **🔐 SecureVault**: cassaforte password crittografata AES-256-GCM con Master Key, import/export CSV Google Password Manager, generatore password e auto-lock per inattività.
6. **🔍 Cerca & Backup**: ricerca globale trasversale e backup/ripristino totale in JSON o esportazione Excel CSV.
